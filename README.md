## 🔧 Troubleshooting Common Issues

**Problem: The download won't start**
Solution: Check your internet connection and try again. You can also try a different browser like Chrome or Firefox.

**Problem: Windows says the file is unrecognized**
Solution: This sometimes happens with new software. Click "More info" then "Run anyway" on the warning screen.

**Problem: The app won't open after installation**
Solution: Close the program and reopen it. If that doesn't work, restart your computer and try again.

**Problem: Can't see the image I want to crop**
Solution: Make sure your image is in a common format like JPG, PNG, or GIF. If your image is still not showing, try converting it using an online tool first.
